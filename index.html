How to get a perfect print / PDF
  1. One-click PDF downloads the exact A4 cover as a PDF file straight to your device.
  2. Print preview opens the browser print dialog — pick printer or Save as PDF, paper A4, margins None. Strictly one page.
  3. Overleaf: download .tex + place ruet_logo.png beside it, compile with pdfLaTeX.
  4. Tap-to-edit: click any line in the preview to jump to its field. Double-click edits text in place.
