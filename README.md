# RUET Lab Report Cover Page Generator

A web-based tool for generating cover pages for RUET (Rajshahi University of Engineering & Technology) laboratory reports.

## Features

- Live preview of the cover page
- PDF export (via browser print)
- Multiple font options (Noto Serif, P052, Palatino Linotype, TeX Gyre Pagella)
- Responsive design for all screen sizes
- Date picker for experiment and submission dates

## Usage

1. Fill in the form fields on the left panel
2. Preview updates automatically
3. Click **PDF** to save/print as PDF
